# NoteNest frontend

This directory contains the React frontend for NoteNest.

## Run locally

From this directory:

```bash
npm install
npm start
```

The development server runs at `http://localhost:3000`. The frontend expects the NoteNest API at `http://localhost:5000/api`; start the backend from the sibling project directory before using the app.

## Available scripts

```bash
npm start         # Start the development server
npm test          # Run tests
npm run build     # Create a production build
```

For complete project documentation, including backend setup, MongoDB configuration, API endpoints, upload rules, and troubleshooting, see the [project README](../../README.md).
